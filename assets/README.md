# Assets Folder

This folder contains images, icons, and other static files used in the app.

## Structure

```
assets/
├── images/          # App images (logos, backgrounds, etc.)
└── icons/           # Custom icons
```

## Adding Images

1. Place your images in the appropriate subfolder
2. Reference them in your code:
   ```dart
   Image.asset('assets/images/your_image.png')
   ```

## Image Guidelines

- Use PNG for images with transparency
- Use JPEG for photos
- Optimize images before adding (use tools like TinyPNG)
- Recommended sizes:
  - App icon: 1024x1024px
  - Tour images: 800x600px
  - Event images: 800x600px
